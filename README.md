# rtl-viewer

FPGA/ASIC 源码工程查看器：打开源码文件夹（或把文件夹直接拖进窗口），自动识别 Verilog/SystemVerilog/VHDL 源码与 Vivado IP 核（`.xci`）。顶部提供工程与文件操作，左侧为工程层级与当前文件大纲，中间为 Monaco 编辑器，右侧可打开端口映射或信号链分析；支持原有深浅主题切换。

## 功能

- **层级树**：从顶层模块按例化关系逐层展开；多顶层时自动识别（仿真环境向内解包出真实顶层），树上方下拉可切换；点击节点打开模块定义，节点行的 ↩ 图标或右键菜单「跳到例化点」跳到父模块中的例化点（右键另含「查看例化处」——列出工程内例化该模块的所有位置并点击跳转，以及复制模块名/文件名/路径/所在目录、在资源管理器中显示，未使用与约束分组同样支持）；IP 核显示为黑盒节点（点击跳到例化点，悬停例化名可看端口连接表）；无父无子的孤儿模块（未被例化、也不例化任何模块的定义）归入「未使用」分组；循环例化标注不展开。
- **紧凑层级与键盘导航**：顶层模块标签与下拉选择同一行显示，长名称保留完整悬停提示。模块树每行 28 px，实例名单行显示，悬停查看完整实例名、模块定义名与路径；跳到例化点按钮在悬停或键盘聚焦时显示。方向键上下移动、左右展开或收起，Home/End 到首尾，Enter/空格打开定义，Tab 可进入例化点按钮。大量模块在层级区内部滚动，深层名称随键盘焦点滚入视口，不挤走大纲。
- **节点类型图标**：普通模块保留方形模块图标，IP 核为紫色菱形；BUFG、DCM 等已识别厂商原语使用青绿色侧边引脚芯片图标和正常文字，未解析模块使用灰色问号。悬停及辅助读屏均提供类型与定义名。
- **全局搜索**：顶部「搜索」或 Ctrl+Shift+F 展开编辑区下方的独立搜索面板，可与工程层级、文件大纲及右侧分析同时显示；拖动上边缘或聚焦分隔条后按上下方向键调整高度。再点「搜索」、面板关闭按钮或输入框内 Esc 收起并保留查询与结果。搜索包含当前工程已打开文件的未保存内容，按文件分组展示、命中高亮，点击结果精确定位并选中命中内容；源码变化后提示刷新结果；Aa 切换大小写敏感、「词」整词匹配、「.*」正则表达式（无效正则有提示）；编辑器里 Shift+F12 或右键「查找引用」对选中/光标下的标识符做字面整词全局搜索，不继承手工正则选项；Verilog 区分大小写，VHDL 不区分大小写。
- **当前文件大纲**：侧栏下方列出当前文件的模块/信号/进程/例化，always/process 块带赋值目标（一眼区分块用途），顶部过滤框键入即筛，点击跳行；面板高度可拖拽调整、可折叠（状态记忆），「⊙」按钮弹出可模糊过滤的符号列表（同 Ctrl+Shift+O），回车跳转；光标移动时状态栏显示面包屑「模块 › 进程」，大纲对应条目同步高亮。
- **导航历史**：跳转前自动记录位置，Alt+←/→ 或编辑器面包屑栏按钮前进后退；左右编辑区各自维护历史，返回时恢复行、列与单行选区，不把另一侧的阅读路径带过来。
- **例化端口悬停与侧栏**：鼠标悬停在例化名上显示连接表。侧栏查看最近明确选择的树实例，Ctrl+K 或编辑器右键「查看端口连接」可查看源码当前位置。点连接信号跳父模块声明，点端口跳子模块声明；普通光标移动、切标签及面板内跳转均保留正在查看的实例，无需钉住。收起再打开保留内容和滚动位置；选择另一实例才更新，切换工程才清空。源码变化时提示刷新。
- **信号链分析**：光标位于信号名时，点击顶部「信号链」或编辑器右键「分析信号链」，查看来源、去向与分支；沿 Verilog/VHDL 命名或位置端口连接、直接标识符赋值跨层追踪。分支默认折叠，显示短实例路径、过程使用数量与后续连接数，展开后查看声明、文件行号及停止原因；悬停名称可看完整实例路径。相同模块的多个实例可通过路径下拉切换，从树进入时优先使用选中路径；节点可跳源码。分析使用当前缓冲区快照，收起再打开恢复原目标和展开状态；结果不随导航跳动。源码变化时提示「刷新当前信号链」，刷新保留原信号及实例；「分析光标处信号」用于主动选择新的分析目标。与端口映射共用右侧空间，进入分屏时收起。
- **编辑器**：Monaco（VS Code 内核），Verilog/SV/VHDL 语法高亮；多标签页（右键：关闭/关闭其他/关闭右侧、复制文件名/路径/所在目录、在资源管理器中显示）、未保存 `*` 标记、保存（Ctrl+S）/另存为/新建、查找替换、Ctrl+Click 跳转模块定义、Ctrl+/ 切换行注释、Alt+Z 切换自动换行（编辑器右键菜单也有入口）、Ctrl+滚轮缩放字号。
- **新建 HDL 文件**：点击「新建 .v」或 Ctrl+N 直接创建文件，右侧下拉选择 `.v`、`.sv`、`.vhd` 时立即新建并记住类型，重启后继续使用；打开其他类型的文件不会改变偏好。空白标签在保存前即可使用对应语言的高亮、补全和注释。首次保存默认带上后缀，目录优先沿用当前文件所在目录，其次为工程根目录。
- **路径与菜单**：编辑区路径中的目录可点击打开对应文件夹，文件名可点击在资源管理器中定位。路径过长时将祖先目录收进「…」，保留父目录与文件名，悬停查看完整路径。切换标签时活动标签自动滚入视口；新建类型、最近工程、编码及应用右键菜单支持方向键、Home/End、Enter/空格和 Esc，关闭后恢复焦点。
- **列编辑**：Alt+Shift+拖动或 Alt+Shift+方向键建立矩形选区，可直接输入、删除；编辑器右键也可切换矩形选择模式。按 Alt+C、顶部「列编辑」或编辑器右键「列编辑…」批量插入文本或数字，支持初始值、增量、重复次数、十／十六／八／二进制、前导零／空格及十六进制大小写，显示作用范围与结果预览。数字输入框按所选进制解释，空增量为 0、空重复次数为 1。矩形／多光标按从上到下的实际选区替换；仅有单光标时从当前列处理到文件末尾，短行补空格，Tab 内插入保持后方对齐。一次撤销恢复整批操作；本次运行期间记住上次成功使用的设置。
- **代码补全**：输入即提示（Ctrl+Space 手动触发）当前文件信号、端口、参数与例化名、全工程模块名、语言关键字和常用块 snippet。独立例化位置选中模块名时，Verilog 生成 `#(...)` 参数与端口骨架，VHDL 生成 `entity`、`generic map` 与 `port map`，保留已输入的标签和库名；Tab 逐项编辑占位符。未写完的例化中，连接左侧提示尚未填写的端口／参数名，右侧提示当前文件信号；参数默认值与同名连接是可修改模板，需按目标工程检查类型、宽度和表达式。
- **分屏双视图**：顶部「分屏」、Ctrl+\、编辑器右键「在另一侧视图打开」或标签右键「向右拆分视图」把编辑器分成左右两组，两组各看各的文件；同一文件在两侧共享缓冲区和未保存状态，编辑实时互通。进入分屏时收起右侧分析面板，为两侧编辑区留出空间，也可手动重新展开；两组间的分隔条可拖拽调宽。顶部「分屏」或第二组收起按钮仅隐藏右侧，保留标签、未保存内容、阅读位置和分栏宽度，再打开恢复。关闭文件使用标签上的关闭按钮。
- **约束文件查看**：`.xdc`/`.sdc` 以「约束」分组展示在树中，使用 Tcl 语法高亮（IP 生成目录的约束不进索引）。
- **外部变更监视**：文件在磁盘被外部修改时，干净标签自动重载、未保存标签标 ⚠；保存时若磁盘已变，弹出「覆盖 / 放弃重载 / 取消」三选，防误覆盖 Vivado 重新生成的内容。
- **最近工程**：工具栏 ▾ 下拉或 Ctrl+R 列出最近打开的 8 个工程，一键切换。
- **编码自适应**：自动识别 UTF-8/UTF-8 BOM/UTF-16/GBK，默认按原编码写回；状态栏可「以指定编码重新打开 / 以指定编码保存」（Notepad++ 语义），支持 UTF-8、UTF-8 BOM、UTF-16 LE/BE、GBK、GB18030、Big5、Shift-JIS、EUC-KR、Windows-1252，兼容 Vivado 默认 ANSI（GBK）工程。
- **快速轻量**：结构扫描只提取模块与例化边，端口按需解析；IP 生成目录不进索引；Windows 单 exe 便携运行，免安装。
- **关闭与工程切换**：关闭脏文件、批量关闭、切换工程和退出提供「保存并关闭／不保存／取消」，默认取消；保存失败或另存为取消时停止操作，全部确认和保存成功后才关闭标签。两侧共享文件只确认一次，单独关闭一个视图而另一视图仍打开时保留缓冲区。
- **应用标题栏**：品牌栏承担窗口拖动与双击最大化，右上角提供最小化、最大化／还原和关闭。关闭按钮与系统关闭请求共用未保存检查；浏览器预览不显示桌面窗口按钮。

## 技术栈

Tauri v2（Rust 后端：文件扫描、编解码、对话框）+ Vite + TypeScript + Monaco Editor；测试用 Vitest（前端）与 cargo test（Rust 编码层）。

## 信号链分析边界

这是源码层面的连线追踪，不执行综合、仿真或完整 HDL elaboration。运算、切片／范围转换、过程逻辑、黑盒、未知方向、多个 architecture 未确定绑定及 `generate` 均显示停止原因；不会穿过寄存器推导依赖或宣称位级等价。未发现可继续解析的连接不代表信号未使用。分析有循环检测、深度和节点预算，达到上限会标明未完全展开；未在当前顶层找到实例时，仅分析当前模块范围。

## 构建与运行

```bash
npm install
npm run build         # 前端构建（tsc 类型检查 + vite）
npm test              # 前端单元与集成测试
npm run tauri dev     # 开发运行（另需 Rust 环境，见下）
```

Rust 端命令通过 `scripts/Invoke-Cargo.ps1` 执行（自动引入工具链与 MSVC 环境）：

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File scripts/Invoke-Cargo.ps1 test --manifest-path src-tauri/Cargo.toml
```

打包便携 exe 必须走 tauri CLI（裸 `cargo build` 产出的是 dev 模式 exe，界面依赖 dev server，无法独立运行）：

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File scripts/Build-Release.ps1
```

产物 `src-tauri/target/release/rtl-viewer.exe` 即为便携可执行文件，双击运行。

前置：Rust stable（本机经 `D:\workspace\toolchains\rust\`，项目 `rust-toolchain.toml` 固定 1.98.1）、Node 24、WebView2 Runtime（Win10/11 自带）。

## 目录

```text
src/         前端：parser/（HDL 解析）、model/（索引、层级树、搜索、导航历史、大纲、信号声明定位）、editor/（Monaco、标签页、代码补全）、ui/（树、搜索面板、大纲、状态栏、对话框、右键菜单、最近工程）
src-tauri/   Rust 后端
tests/       Vitest 测试（含真实工程验收：tests/acceptance-cp7.test.ts 夹具在 .tmp 不入库；tests/acceptance-real-projects.test.ts 依赖本机绝对路径工程，路径缺失时自动跳过）
scripts/     构建辅助（Build-Release.ps1、Invoke-Cargo.ps1、make-icon.mjs）
```
