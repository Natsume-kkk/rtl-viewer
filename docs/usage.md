# 使用指南

[返回项目首页](../README.md)

## 打开与浏览工程

点击“打开文件夹”、按 `Ctrl+Alt+O`，或将源码文件夹拖入窗口。应用扫描 Verilog／SystemVerilog／VHDL 源码、Vivado IP 配置和约束文件；“最近打开的工程”保留最近 8 个目录。可以先打开 [独立样例](../tests/samples/basic) 熟悉操作。

### 层级树

工程按模块例化关系展示，多顶层时可在树上方切换。节点显示“实例名 : 模块名（定义文件名）”，顶层与未使用模块只显示模块和文件名；长名称悬停可查看完整内容。点击模块打开定义，节点右侧按钮跳到父模块中的例化位置；右键“查看例化处”列出工程内的例化位置。

Vivado IP 显示为黑盒节点，使用模板或 stub 中的端口信息，不展开生成源码。已识别厂商原语作为叶子显示，未解析模块标记为 unresolved；循环例化停止展开。未被例化且不例化其他模块的定义归入“未使用”，`.xdc`／`.sdc` 约束文件单独分组并使用 Tcl 高亮，可以正常编辑、保存和选择编码。

树中可用方向键移动和展开，Home／End 到首尾，Enter 或空格打开定义，Tab 聚焦跳转按钮。层级与大纲独立滚动；侧栏宽度可拖动调整并在重启后恢复。节点右键还提供复制名称／路径和在资源管理器中显示等操作。

扫描跳过 Vivado 的 `*.runs`、`*.sim`、`*.cache`、`*.hw`、`*.gen`、`*.ip_user_files` 及点开头目录。单独打开文件只增加编辑标签，不切换工程，也不自动将工程外或被排除的文件纳入工程索引。

### 大纲与导航

当前文件大纲列出模块、信号、进程和例化；进程旁显示赋值目标。输入过滤词可缩小范围，点击条目跳转源码；`Ctrl+Shift+O` 打开符号搜索。光标所在模块和进程显示在编辑区面包屑中。

`F12` 或 `Ctrl+Click` 跳转模块定义，`Alt+←`／`Alt+→` 在阅读位置间后退和前进。分屏两侧各自保存导航历史。路径中的目录和文件名可分别打开目录或在资源管理器中定位文件。

按住 Ctrl 悬停模块名可预览定义，无需先打开目标文件；目标已打开时使用当前未保存内容。`F1` 打开命令面板，可搜索“追踪”“矩形”“列编辑”等动作，执行于当前编辑视图。

## 搜索

`Ctrl+Shift+F` 或顶部“搜索”打开编辑区下方的搜索面板，按文件分组展示匹配项，点击结果定位并选中源码。搜索包含工程中已打开文件的未保存内容；内容变化后可刷新结果。

支持大小写、整词和正则表达式开关，无效正则会显示提示。`Shift+F12` 或右键“查找引用”对当前标识符执行字面整词搜索；这不是完整语义引用分析。Verilog 搜索区分大小写，VHDL 不区分大小写。

单次搜索超过 2 秒会停止并提示，可简化查询后重试。修改查询或收起面板会取消正在进行的搜索；已完成的结果保留。结果最多显示 500 个命中行，每行预览最多 2000 字符、200 处高亮，点击仍按原始位置跳转。

搜索、信号链、层级和大纲可以同时显示。拖动搜索面板上边缘调整高度；关闭按钮、顶部“搜索”或搜索框中的 Esc 收起面板，查询与结果保留。

## 信号链

### 发起与刷新

在源码中的端口或内部信号上右键选择“追踪此信号”。分析使用当前编辑缓冲区快照；移动光标、切换文件和点击树节点不会改变追踪目标。顶部“信号链”只显示或收起面板。

当前信号以强调边框标记，源码定位图标跳到对应位置。源码改变后保留旧结果并提示刷新；点击刷新重新分析原目标。收起面板或定位源码均保留追踪目标和阅读状态。

卡片宽度默认按内容自适应，最小 236 px、最大 560 px。拖动卡片右边缘可单独加宽至 1200 px 覆盖自适应结果，后续列和连线同步调整；超出面板宽度时可横向滚动。双击右边缘恢复自适应；键盘 Tab 聚焦调整边缘后，左右方向键每次调整 24 px，Home 恢复自适应。收起、展开、隐藏面板和同目标刷新保留手动调整的宽度；切换追踪信号、实例路径或过程作用域后恢复自适应，不跨应用重启保存。

### 端口连接

`input`／`output`／`inout`（包括 `output reg`）展示左侧来源、中央当前信号和右侧去向。连接按真实实例路径区分复用模块，沿端口映射追到赋值位置或顶层接口；顶层端口卡片标明外部输入、输出或双向边界。

赋值卡片区分“驱动赋值”和“读取赋值”。已显示端口的直接赋值终点默认可见，多路分支也不需要先点“继续追踪”才能看到对应赋值；更深的端口路线仍按路展开。同一进程对同一目标的条件赋值合为一张源码卡片，保留条件与语句顺序；不同进程或实例分别显示。点击过程标题可收起代码，点击赋值行旁的定位图标查看原文。赋值展示到这一层即停止，不沿赋值目标继续扩散，也不分析其他操作数的来源。需要单独分析另一个内部信号时，在对应源码上重新右键追踪。

### 模块内逻辑

内部 `reg`／`wire`／`signal` 的依赖图只分析当前模块，在本模块端口或子模块端口处停止。子模块端口卡片直接附上第一层实际语句：输入端口显示直接读取它的赋值和条件／时钟用途，输出端口显示直接驱动它的位置，双向端口分别显示直接读写。单纯的端口转接会继续向子模块追到第一处实际赋值或使用语句，保留实例路径；“第一层”按实际赋值／使用计，不按模块层数计。

这些源码片段不会展开其他操作数的来源或赋值目标的后续去向，也不会切换原追踪目标。过程源码可就地收起／展开；定位按钮跳到源码，子模块端口不再提供切换到完整模块依赖图的入口。

单路连接直接延伸，扇出先列出各直接去向；点击分支或“继续追踪”展开该路，再次点击收起后续。可以同时展开多路，也可使用“全部展开／全部收起”。收起一条路线会保留前缀、下级选择和其他路线仍在使用的汇合节点。

条件保留 `if`／`elsif`／`case`／`when` 结构。寄存器当前值 Q 与更新逻辑分别显示；赋值保留原始运算符与时钟条件。未知方向使用无箭头连接，不算作已确认驱动。

位选、切片、数组与字段写入在无法可靠合并为完整更新值时，显示“源码关系”：保留原始目标、条件、循环头和赋值顺序，可逐行定位。数组读取区分数据对象与地址引用；未知调用保留参数引用并注明调用内部未展开。声明初值单独展示，不表示仿真后的当前值，也不算持续驱动。选择 `rom_type` 等类型名称时，面板提示对象类型并提供“查看定义”，保留已有信号链。

### 终点提示

“无后续引用”表示在可分析范围内未发现下游读取或连接，“无赋值来源”表示未发现上游赋值；条件和时钟用途也计为引用。`KEEP` 等属性不算逻辑读取。缺失定义、绑定不明和不支持的语句会显示具体原因，与正常终点区分。

## 编辑与保存

### 文件与标签

`Ctrl+N` 新建 HDL 文件，工具栏下拉选择 `.v`、`.sv` 或 `.vhd` 并记住类型。`Ctrl+O` 打开单文件，`Ctrl+S` 保存，`Ctrl+Alt+S` 另存为。首次保存默认带上所选后缀，目录优先使用当前文件目录，其次为工程根目录。

编辑器支持高亮、查找替换、自动换行、字号缩放和补全。补全包含当前文件信号、端口、参数、全工程模块与语言片段；例化位置可插入模块端口骨架，Tab 切换占位符。补全结果需按目标工程核对类型、位宽和连接表达式。

菜单、按钮和提示使用统一的界面字体；源码、模块名和信号卡片使用同一套等宽字体。源码初始字号为 14 px，窗口变窄时不会自动缩字；可用 `Ctrl+鼠标滚轮` 单独缩放源码。

未保存标签显示星号。同名文件追加最短区分目录，悬停可查看完整路径；标签右键提供批量关闭、复制路径和定位文件。

### 双视图与标签拖动

顶部“视图”、标签右键和编辑器菜单均提供“移动到另一视图”与“克隆到另一视图”：移动会移走原侧标签；克隆让同一文档在两侧同时显示，共享编辑内容、保存状态和撤销记录，两侧各自保留光标、选区、滚动位置和导航历史。`Ctrl+Alt+V` 克隆当前文档，`F8` 切换焦点。未命名文件同样支持移动与克隆，首次保存后两侧使用同一路径；已有文件另存为时，另一侧仍保留旧路径文档。

抓住顶部文件名标签可进行以下操作：

- 在当前标签栏中拖动，调整标签顺序；拖到标签上插入其前方，拖到空白处放到末尾。
- 单视图时拖到编辑区松开，选择“移动到另一视图”或“克隆到另一视图”。
- 双视图时拖到另一侧编辑区或标签栏，直接移动；反向拖回可合并，任一侧最后一个标签移走或关闭后，空视图自动收起。
- 拖动中显示落点提示；按 Esc、失去窗口焦点或在有效区域外松开会取消。拖动仅在当前应用窗口内进行，不创建独立窗口。

“视图”菜单和分隔条右键菜单提供左右排列、上下排列、交换两侧位置及独立的纵向／横向同步滚动开关。同步默认关闭，开启时以两侧当前阅读位置建立相对偏移；切换标签或恢复双视图后重新建立偏移。拖动分隔条调整大小，也可聚焦分隔条后用方向键调整、Home 恢复均分，`Shift+F10` 打开布局菜单。

“收起另一视图”保留当前侧，隐藏侧的标签、未保存内容和阅读位置保留；通过“恢复双视图”继续阅读。分屏不会收起信号链或搜索面板。

Windows 路径仅大小写或斜杠方向不同，也视为同一文件，共享编辑内容和保存状态。

### 列编辑

`Alt+左键拖动` 或 `Alt+Shift+方向键` 建立矩形选区，支持直接输入、删除和粘贴。`Alt+C` 打开列编辑，可批量插入文本或数字，设置初始值、增量、重复次数、进制和填充方式。输入数字按所选进制解释，空增量为 0，空重复次数为 1。

矩形／多光标按选区从上到下替换；只有单光标时，从当前列处理到文件末尾。短行自动补空格，Tab 内插入保留后方对齐，整批操作可一次撤销。

### 编码与外部修改

读取时自动识别 BOM、严格 UTF-8 或 GBK，默认使用原编码保存。状态栏提供“以指定编码重新打开”和“以指定编码保存”，可选择 UTF-8、UTF-8 BOM、UTF-16 LE／BE、GBK、GB18030、Big5、Shift-JIS、EUC-KR 和 Windows-1252。损坏编码和 UTF-32 拒绝读取，单文件上限为 64 MiB。

文件被外部修改时，未编辑的标签自动重载，有未保存内容的标签显示警告。保存时发现磁盘变化会要求选择覆盖、放弃重载或取消；文件已删除时，保存前确认是否重建。

关闭文件、切换工程或退出时，未保存内容提供“保存并关闭／不保存／取消”。取消或保存失败会停止操作；共享文件只确认一次，收起分屏不会丢弃未保存内容。

同一文件的连续保存依次写入，关闭操作会等待正在进行的保存完成。读取期间发生编辑或保存时，过期的重载结果不会覆盖当前内容。

| 关闭当前／全部文件 | `Ctrl+W`／`Ctrl+Shift+W`，全部关闭涵盖两侧视图 |

| 剪切／复制／删除整行 | `Ctrl+L`／`Ctrl+Shift+X`／`Ctrl+Shift+L` |

## 分析边界

这是源码层面的静态分析，不执行综合、仿真或完整 HDL elaboration。分支展开是阅读操作，不表示条件实际成立，也没有周期值或时间波形。

| 范围 | 行为与限制 |
|---|---|
| 表达式 | 支持常见运算、三目选择、并发 `when/else`、常量聚合、位选／切片与精确 `case`；动态下标区分数据与地址，保留原文，不计算运行时选择结果 |
| 过程赋值 | 对支持的 Verilog `always` 和 VHDL `process` 保留语句顺序，区分阻塞／非阻塞及变量／信号赋值；部分写入和过程循环保留源码关系，不推导完整更新值或执行循环 |
| 类型与数值 | 识别常见数组、记录／结构、枚举与声明初值；常见转换保留名称和参数，不计算完整位宽／符号传播、重载、四态值或驱动强度 |
| 局部对象 | 过程、块与循环声明的局部对象和模块同名对象隔离；局部赋值追踪可能列出同一过程的多个候选赋值。生成块中同一源码对应多个展开对象时，实例路径列表显示各生成路径，可切换查看，刷新保留当前选择 |
| 分析停止 | 未知函数／任务／过程调用保留参数和源码，标明内部语义未展开；未知结构只对相关对象保留边界，无法可靠确定的结果不继续推导 |
| 模块绑定 | 模块内绑定发起位置的文件和实现；跨层同名定义或多个 architecture 无法确定时停止，不混合推导 |
| 参数与 generate | 信号分析按实例应用常见 parameter／generic 覆盖，处理支持范围内参数的位宽截断与符号，保留生成块局部常量的作用域；在有界整数常量范围内选择 `if generate`、展开 `for generate`。不能确定的类型、条件、范围、复杂宽度运算及超预算展开会在对应区域停止 |
| 黑盒与展开 | IP 按黑盒处理；未知方向不猜测，递归例化和展开预算会提示截止；不执行宏预处理、完整 package／configuration 解析或完整 HDL elaboration |

VHDL 过程内的函数和子程序不会混入外层赋值，调用按边界处理。未在当前顶层找到实例时，仅分析当前模块。未找到可解析连接不代表信号未使用。
