# 信号运算过程样例

[返回项目首页](../../README.md)

独立的源码运算图阅读实验。桌面软件已复用其分析层接入端口连接与模块内逻辑两种模式；此页面保留单路径选择实验，与正式界面的多分支展开不同。参考表达式数据流与局部展开方式；路径和分支由本地 RTL 文本解析生成，不使用手工连线数据，不运行仿真。

## 生成与打开

在项目根目录安装既有依赖后运行：

```powershell
node examples/computation/build.mjs
Start-Process -FilePath (Resolve-Path .tmp/computation-preview/index.html).Path
```

生成页面是可以离线打开的单个 HTML，包含算术／寄存器／限幅和混合语言双向端口两个精简样例。生成脚本使用现有 Vite 依赖树中的 esbuild，未新增包或外部服务。

可显式传入截图对应工程的 Verilog 顶层与 VHDL 驱动文件，增加 `temp_top.dq_in_1` 的真实源码快照：

```powershell
node examples/computation/build.mjs "<source-directory>/module ds18b20_top.v" "<source-directory>/ds18b20_temp.vhd"
```

真实文件只读，按 UTF-16 BOM、严格 UTF-8、GBK 兜底解码。源码快照只进入本机 `.tmp/computation-preview/index.html`，不纳入精简样例。该页面包含所传文件全文，按本地工程文件管理。

## 操作

- 页面按软件布局展示：左侧实际模块例化树与信号列表，上方源码，下方横向运算路径。它是独立的嵌入效果预览，源码区使用轻量 HTML 高亮与页内编辑，本页面不使用正式 Monaco；正式功能见项目根 README。
- 点击源码信号或左侧信号，展开对应路径；点击运算节点或其定位按钮，上方源码定位高亮，追踪目标保持不变。跨实例源码点击使用该节点所属实例，避免复用模块串链。
- 遇到分支停下，点击 `if`／`else if`／`elsif`／`else` 或 `?:`／`when/else` 的一行后接出后续路径。已读前缀、节点位置及已选条件保留；选择复位、保持或常量不会删除前面的运算。未取用的已有数据连接改为虚线，当前数据依赖为实线。
- 点击已选条件改选，仅重建该分叉的后续内容并清除后续选择；嵌套分支逐层进入，同模块不同实例的选择隔离。时钟单独标注，保持分支显示 `Q → Q`。
- 下方“继续”进入下游信号；“返回”恢复上一目标及阅读路径。“重选路径”清除分支选择；切换目标或样例重新开始。顶部“信号链”收起／恢复下方面板并保留当前内容。
- 拖动源码与路径之间的分隔条，或聚焦后使用上下方向键调整高度。长路径在下方面板内部横向滚动。路径标题旁的“追踪设置”可更改实例、目标及来源深度；达到深度上限时点击节点上的“继续展开”。
- “编辑”与“重新解析”只修改页面内源码快照，并清空过期路径；编辑期间不允许切换源码文件，防止写入错误快照。重新载入恢复生成时的内容，不写入真实工程。

所选分支是阅读假设，不是仿真结果，也不自动验证多个条件能否同时成立。虚线保留阅读上下文，不代表该分支仍使用前面的数据。分支代码按解析结果整理，隐含保持和类型转换显式标注，可通过上方源码核对原语句。

## 已实现的分析范围

- Verilog 常见一元／二元表达式、三目选择、静态位选／切片、拼接、连续赋值与单目标 wire 声明赋值。
- VHDL 常见表达式、并发 when/else；已识别向量对象的静态切片；大小写归一。
- 受支持的 always/process 内顺序赋值、if/else/elsif 与精确 case 分支。Verilog 阻塞／非阻塞、VHDL 变量／信号赋值使用分开的立即值与延迟提交环境；后赋值按条件覆盖先赋值。立即写入保留类型转换节点，不把窄目标直接等同于原右值。
- 寄存器当前值与更新规则分开，保留时钟、敏感表和未更新路径。过程 if/case 与表达式三目选择分别保留表达语义，不以三目运算代替过程的四态控制语义。
- 按实例路径跨语言连接。顶层 inout 单独显示内部驱动与外部来源，`Z` 标为释放驱动；多个来源不伪装成优先级选择。
- 点击／悬停与源位置关联；图中数据来源可逐层展开。颜色来自项目深浅主题令牌。

## 分析边界

本实验复用当前文本级模块／端口解析器，不是完整语言前端。宏、generate 展开、复杂绑定、黑盒和缺失定义沿用显式边界。循环、部分目标写入、混合赋值、局部子程序与不支持的过程结构停止该过程的更新推导；未知表达式、动态下标和函数／转换调用保留原文边界。

声明类型与范围按原文展示；不承诺完整位宽／符号传播、赋值转换求值、重载解析、总线强度或四态值求解。未完整辨认的 VHDL 位选／调用不猜测。没有仿真值和周期时间轴；组合路径缺省值表示存储依赖，不自动断言为触发器。
